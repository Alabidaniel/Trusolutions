# Therapist Screen Added

TherapistScreen.js created and integrated:

- Accessible from HomeScreen therapist card and "Find a Therapist" button.
- Features therapist list with search, ratings, book buttons.
- Matches app design and navigation.

To test:

1. Run `cd trusolution && npx expo start` in terminal (install deps if needed: `npm install`).
2. Navigate to Home tab → click Therapist card or button → view screen.

Fully functional.
